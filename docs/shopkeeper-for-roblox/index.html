Shopkeeper for Roblox

Bulk tools for game passes and developer products in the Roblox Creator Hub. Create, reprice, rename and put items on or off sale in bulk, with a preview before every change and an undo after it.

Live on the Chrome Web Store · coming to Edge
Add to Chrome Shopkeeper's website Privacy policy

What it does

A game's whole store in one step

Bulk create

Make game passes and developer products from a preset (a donation board, starter passes, currency packs) or from your own list, with names, prices, descriptions and images.

Bulk edit

Raise or lower prices by a percentage or a number of Robux, set one price for many items, put items on or off sale, rename them and edit descriptions.

Preview and undo

See the old and new value of every item before anything changes. Every bulk change is saved in a history on your computer, and Undo puts the old values back.

Built to be safe

It never reads, stores or sends your Roblox login cookie or password, and doesn't even ask for the cookies permission. It only runs on create.roblox.com and talks only to Roblox's own servers.
