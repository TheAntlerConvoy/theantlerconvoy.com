# theantlerconvoy.com

The Antler Convoy's public site, served by GitHub Pages from this repository's `main` branch at
https://theantlerconvoy.com (the `CNAME` file). Plain HTML and one stylesheet; nothing to build.

| Path | What |
|---|---|
| `index.html` | Home: what The Antler Convoy makes, one card per venture |
| `ebay-store/` | The eBay store |
| `sold-sorter/`, `flipcomp/`, `shopkeeper-for-roblox/` | One page per browser extension |
| `support/`, `privacy/` | Contact, and this site's privacy note with links to each product's policy |
| `404.html` | GitHub Pages shows this for an address that doesn't exist |
| `assets/` | `site.css`, the fonts, the logo, the link-preview image (`og.png`) and screenshots |

Each extension also has its own site at `theantlerconvoy.github.io/<name>/` (separate repositories).
Their `privacy.html` addresses are built into the published extensions and their store listings, so
those repositories and pages must stay where they are.

When an extension goes live in a store, change its "Coming soon" status (its page and its card on the
home page) and add the store buttons.
